# Ph0: 11/13 | K.26: Test corpus, golden images and interop suite

**Tag:** K.26; **Priority:** P0; **Phase:** 0 onward; **Needs:** K.3; **Code:** `tests/corpus/`, `tests/golden/`, `tests/interop/`, `crates/ecclesia-mupdf/tests/corpus.rs`
**Plan:** §27 entry `Ph0: 11/13 | K.26`, §16, Appendix C.4.

## Problem

Single-file smoke tests miss format edge cases, theme contrast regressions, RTL/AcroForm structures, and interoperability bugs with external PDF readers.

## User story

As a user sharing annotated or exported PDFs, I want EcclesiaPDF tested across PDF, EPUB, XPS, CBZ, FB2, MOBI, SVG, HTML, Markdown, RTL, and AcroForm documents and checked against external PDF oracles, so that files open reliably everywhere.

## UI sketch

None; automated test suites in CI.

## Mode

All modes.

## Speed and size impact

Test assets live strictly under `tests/` and never ship in the core binary or installer.

## Design

- **`tests/corpus/`:** redistributable corpus generated by `tests/corpus-src/make_formats.py` and `make_pdf_corpus.py`, covering PDF (`zlib-manual.pdf`, `base14-outline-annot.pdf`, `heavy-vector.pdf`, `rtl-arabic-biditest.pdf`, `acroform-fields.pdf`, `ten-page-paper.pdf`) plus EPUB, FB2, MOBI, HTML, MD, SVG, CBZ, PNG, and XPS.
- **`tests/golden/`:** `manifest.json` defining canonical page geometry, text assertions, and perceptual comparison tolerances across Light, Dark, and High-Contrast themes.
- **`tests/interop/`:** `checklist.json` and `verify_interop.ps1` verifying structural PDF invariants and running `qpdf --check`, `pdftotext`, and `pdfsig` when installed.

## Acceptance tests

- [x] `every_corpus_file_renders_page_one_to_png_and_gives_text` (`crates/ecclesia-mupdf/tests/corpus.rs`): opens, renders, and extracts text across the full corpus.
- [x] `each_reading_theme_renders_the_corpus_with_aa_text_contrast` (`crates/ecclesia-core/tests/reading_themes.rs`): verifies WCAG AA contrast across built-in themes.
- [x] `tests/interop/verify_interop.ps1`: passes structural and CLI oracle checks across `tests/interop/checklist.json`.
